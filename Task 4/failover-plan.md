## **6. План отказоустойчивости и переключения**

### **Сценарии отказа и порядок действий**

| **Сценарий** | **Обнаружение** | **Решение** | **Шаги** | **Время** | **Потери данных** |
| --- | --- | --- | --- | --- | --- |
| **Отказ VPS в Лагосе (Нигерия)** | Мониторинг Blackbox (uptime \< 5 мин) | **Переключение на резервный сервер в Кении** | 1\. Поднимаем реплику БД (PITR из бэкапа ≤ 15 мин).<br/>2\. Переключаем DNS (Cloudflare) на Kения.<br/>3\. Проверяем работу API (health check).<br/>4\. Уведомляем CEO/CTO. | **RTO ≤ 4 часа** | **RPO ≤ 15 минут** (бэкапы каждые 15 мин) |
| **Отказ VPS в Найроби (Кения)** | Мониторинг Blackbox | **Переключение на GCP africa-south1 (ЮАР)** | 1\. Поднимаем реплику БД (PITR из бэкапа).<br/>2\. Переключаем DNS на ЮАР.<br/>3\. Проверяем работу API.<br/>4\. Уведомляем CEO/CTO. | **RTO ≤ 4 часа** | **RPO ≤ 15 минут** |
| **Отказ GCP africa-south1 (ЮАР)** | Мониторинг GCP, алерт \> 5 мин | **Переключение на AWS af-south-1 (Кейптаун)** | 1\. Промоутим реплику БД в кейптауне.<br/>2\. Переключаем трафик через Cloud Armor/DNS.<br/>3\. Проверяем API.<br/>4\. Уведомляем CTO. | **RTO ≤ 1 час** | **RPO ≤ 5 минут** (синхронная репликация) |
| **Отказ M-Pesa API (Кения)** | Мониторинг **payment_gateway_requests_total**, 5xx \> 5% | **Автоматическое переключение на Flutterwave** | 1\. Circuit Breaker размыкается через 5 мин.<br/>2\. Трафик платежей направляется на Flutterwave.<br/>3\. Пользователь не видит сбоя.<br/>4\. После восстановления M-Pesa — постепенный возврат (canary). | **≤ 5 минут** | **Нет потерь** (транзакции не теряются, очередь) |
| **Отказ Sendbox API (Нигерия)** | Мониторинг **logistics_requests_total**, 5xx \> 10% | **Ручное переключение на Sendy** | 1\. Инженер получает алерт.<br/>2\. Вручную изменяет конфигурацию логистического партнёра.<br/>3\. Проверяет создание тестовой доставки.<br/>4\. Возврат после восстановления Sendbox. | **RTO ≤ 30 минут** (ручное вмешательство) | **Нет потерь** (заказы в очереди) |

### **Кто принимает решение**

| **Сценарий** | **Решение принимает** | **Эскалация** |
| --- | --- | --- |
| Отказ VPS (Нигерия/Кения) | Дежурный инженер (DevOps) | CTO через 30 мин |
| Отказ GCP (ЮАР) | Дежурный инженер + CTO | CEO через 60 мин |
| Отказ платёжного API | Автоматически (Circuit Breaker) | DevOps уведомляется |
| Отказ логистического API | DevOps (ручное переключение) | CTO через 30 мин |
