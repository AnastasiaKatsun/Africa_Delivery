## **3. ADR №3: Стратегия размещения данных**

# **ADR №3: Стратегия размещения данных**

**Статус:** Принят
**Дата:** 07.10.2026
**Автор:** Solution Architect (Анастасия Кацун)

### **Контекст**

NDPR (Нигерия) требует хранения персональных данных граждан Нигерии на территории страны. У AWS, GCP и Azure нет регионов в Нигерии. Юристы предоставят детальные требования через 4–6 недель и рекомендуют не фиксировать архитектуру до их получения. Дедлайн запуска — 15 октября. Требование ЮАР (POPIA) об управлении согласием противоречит маркетинговому плану, основанному на купленной базе из 410 тысяч номеров.

### **Решение**

Принимаем **гибридную модель размещения данных**:

| **Страна** | **Основное размещение** | **Резервное размещение** | **Обоснование** |
| --- | --- | --- | --- |
| **Нигерия** | **Локальный VPS в Лагосе** (Layer3 / RackCentre) | Резервный VPS в Найроби (анонимизированные данные) | NDPR — данные нигерийцев хранятся в Нигерии. |
| **Кения** | **Локальный VPS в Найроби** | GCP africa-south1 (анонимизированные данные) | Kenya DPA — минимум одна копия локально. |
| **ЮАР** | **GCP africa-south1 (Йоханнесбург)** | AWS af-south-1 (Кейптаун) | POPIA — данные резидентов остаются в стране. |

### **Обоснование**

| **Критерий** | **AWS / GCP (ЮАР)** | **Локальный VPS (Нигерия)** |
| --- | --- | --- |
| Соответствие NDPR | (нет региона в Нигерии) | (данные физически в Нигерии) |
| Latency для пользователей | 80–130 мс | **\< 5 мс** |
| Стоимость | $25–50/мес за compute | $50–150/мес за VPS |
| Надёжность (SLA) | 99,95–99,99% | 99,9% (локальный провайдер) |
| Масштабируемость | Высокая | Ограниченная |

### **Обратимость решения (ключевой принцип)**

Архитектура спроектирована так, чтобы **пережить уточнение юридических требований без переписывания системы**:

1. **Абстракция данных:** Приложение работает с данными через API-слой, который скрывает физическое расположение БД. Перемещение данных между регионами = изменение конфигурации (DNS/connection string), а не кода.
2. **Маскирование как механизм, а не как исключение:** Мы сразу проектируем слой маскирования. Если юристы разрешат хранить данные за пределами страны в маскированном виде — мы просто включаем маскирование для резервного региона.
3. **Шифрование с CMEK:** Все данные шифруются с ключами, которые хранятся в стране происхождения данных. Даже если данные будут переданы за границу (резервная копия), они бесполезны без ключей.
4. **Модульность хранения:** Каждая страна имеет свою схему БД (отдельные таблицы/схемы) в своём регионе. Перемещение одной страны не влияет на другие.

### **Последствия**

**Позитивные:**

* Соответствие известным требованиям NDPR, POPIA и Kenya DPA.
* Низкая задержка для пользователей (\< 5 мс в Нигерии и Кении).
* Возможность адаптации после получения юридических уточнений.

**Негативные:**

* Дополнительные расходы на локальные VPS (выше стоимость за ресурсы, чем у hyperscaler'ов).
* Ограниченная масштабируемость локальных провайдеров (при росте потребуется миграция или распределение нагрузки).
* Сложность эксплуатации: несколько регионов, разные провайдеры, разные процедуры бэкапов.

### **Риски и митигация**

* **Риск:** Локальный провайдер в Лагосе окажется ненадёжным. **Митигация:** Выбираем провайдера с SLA 99,9%; настраиваем резервный сервер в Кении; автоматическое DNS-переключение.
* **Риск:** Юристы потребуют дополнительных мер (например, обязательное маскирование при передаче). **Митигация:** Слой маскирования реализован в коде с первого дня; включение = изменение конфигурации.
* **Риск:** Маркетинговый план (база 410k номеров) противоречит POPIA. **Митигация:** Consent-manager обязателен с первого дня; рассылка по купленной базе — только после получения согласия (double opt-in).

### **Решение о согласиях (Consent Management)**

Принимаем **консервативное решение**: без явного согласия пользователя **никакие** маркетинговые коммуникации не отправляются. Это означает:

* Маркетинговая база 410k номеров может быть использована только после подтверждения согласия через SMS/WhatsApp (double opt-in).
* Рассылка до получения согласия — **только транзакционные** уведомления (статус заказа).
